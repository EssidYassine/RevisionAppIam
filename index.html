Core Definition

IAM

Framework of policies, technologies, processes & programs to manage digital identities and govern user access.
Core: Right identity → right access → right resource → right time.

Identity — 3 Data Types

  • Identifiers — unique labels: employee ID, username
  • Credentials — proof: password, certificate, SAML assertion, biometric
  • Attributes — descriptive: name, role, department
4 IAM Pillars

1 Identification

Claiming identity. Must be: Unique · Non-descriptive · Secure

2 Authentication

Type I — Knowledge: password, PIN, OTP
Type II — Possession: token, smartcard
Type III — Biometrics: fingerprint, iris
MFA — 2+ DIFFERENT types

3 Authorization

Need-to-Know · Least Privilege · SoD · Implicit Deny · ACL

4 Accountability

Identity + Action + Object + Timestamp. Logs 1 year, no overwrite.

📄 SAML SP-Initiated Authentication Flow

Service Provider
🔑 IdP
Identity Provider
1 User → SP: Requests access to protected resource
2 SP → User → IdP: SP detects unauthenticated → redirects with AuthnRequest
3 User → IdP: Authenticates (username + password)
4 IdP: Generates & digitally signs SAML Assertion (XML)
5 IdP → Browser → SP: Sends SAML Response to SP's ACS URL
6 SP: Validates signature → creates session → grants access ✅
Key: AuthnRequest SAML Assertion (XML) Digital Signature (IdP Private Key) ACS URL (SP endpoint)

Kerberos Attacks

🔴 Kerberoasting

Request TGTs for SPN accounts → crack hashes offline. Tools: Mimikatz, Rubeus.

🔴 Golden Ticket

Forge TGT with stolen krbtgt key → admin access to ALL services.

🔴 Silver Ticket

Forge ST from computer account → ONE service, no KDC contact (stealthier).

🔴 Pass-the-Ticket

Replay stolen TGT/ST to impersonate user — no password needed.

🔥 MCQ Guaranteed Topics

Preventive vs Detective vs Corrective — Firewall = preventive. IDS/CCTV = detective. Revoking access = corrective. Forensics = detective.
Bell-LaPadula vs Biba — BLP = confidentiality (no read up / no write down). Biba = integrity (no write up / no read down).
MAC vs DAC vs RBAC — MAC = OS enforces labels. DAC = owner decides. RBAC = permissions follow roles.
Identity vs Credential vs Attribute — Identifier = unique label. Credential = proof (password, token). Attribute = description (role, dept).
Subject vs Object — Subject = active (user, process). Object = passive (file, DB).
IdP vs SP — IdP authenticates (Okta, Azure AD). SP provides services (Gmail, Salesforce).
MFA rule — Must use 2+ DIFFERENT factor types. Two passwords = NOT MFA.
Administrative control — Policies, training, procedures. Not firewalls (those are technical).

🔥 Case Study Guaranteed Questions

IAM approach for international company? → Centralized. Eliminates silos, uniform control, audit trail.
Kerberos flow (TGT/TGS 6 steps) — Always appears. Know: AS → TGT, TGS → ST, ST → server.
Compare SSO standards table — LDAP / Kerberos / SAML / XACML / OIDC / OAuth. Know type + token + use case.
JML lifecycle (Joiner/Mover/Leaver) — Know what triggers each. Mover = most complex. Leaver = Day 0.
After a promotion → Mover process — Remove old permissions + assign new + SoD check. Risk: privilege escalation.
Bell-LaPadula for HR files? → Yes — confidentiality model protects salaries & personal records.
Biba for financial systems? → Yes — integrity model prevents tampering of transaction data.
RBAC scenario for HR team — Assistant (read-only), Manager (full access), Director (all + audit logs).
Golden Ticket attack — Forge TGT using krbtgt hash → admin access to ALL. Requires DC compromise.
SAML vs Kerberos — Kerberos = internal network. SAML = external web/SaaS SSO.

🔥 Definitions to Know Word-for-Word

IAM — Framework of policies, technologies, processes & programs to manage digital identities and govern user access.
Orphaned account — Active account with no legitimate owner. Result of delayed deprovisioning.
Privilege creep — Accumulation of access rights across role changes without revoking old ones.
SoD (Separation of Duties) — Sensitive tasks split across 2+ people to prevent fraud and insider threats.
Implicit Deny — Access denied unless explicitly granted. Default = deny.
Least Privilege — Minimum rights + permissions needed to perform the job. Includes action rights, not just data access.
KDC — Key Distribution Center = AS + TGS. Single Point of Failure in Kerberos.
SSI (Self-Sovereign Identity) — Individual controls own identity data with no central authority (blockchain/decentralized).
